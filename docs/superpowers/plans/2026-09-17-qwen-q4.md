# Qwen Q4 Implementation Plan
> For agentic workers: use superpowers:subagent-driven-development; ownership is assigned per task.
Goal: offline Qwen3-ASR-1.7B Q4_K dictation and signed Android APK.
Architecture: minimal CPU Qwen JNI decoder, existing Kotlin batch cache/segmentation and model downloader.
Tech stack: Kotlin, Android, C++17, GGML/CrispASR, Gradle.

- [x] Add app/src/main/cpp/qwen decoder C++ header/source, JNI wrapper and CMake build. Add tools/build-qwen-native.sh pinned source retrieval/build.

- [x] Cross-compile arm64-v8a, inspect ELF and dependencies. Runtime sources fetched to ignored build tree; only project adapter and build recipe tracked.

- Native CTest: 2/2 pass. Metadata leakage regression observed failing before the fix, passing after.
