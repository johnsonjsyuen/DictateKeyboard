# Qwen Q4 Implementation Plan
> For agentic workers: use superpowers:subagent-driven-development; ownership is assigned per task.
Goal: offline Qwen3-ASR-1.7B Q4_K dictation and signed Android APK.
Architecture: minimal CPU Qwen JNI decoder, existing Kotlin batch cache/segmentation and model downloader.
Tech stack: Kotlin, Android, C++17, GGML/CrispASR, Gradle.

## Task 1: Native runtime (native worker)
- [ ] Add app/src/main/cpp/qwen decoder C++ header/source, JNI wrapper and CMake build. Add tools/build-qwen-native.sh pinned source retrieval/build.
- [ ] Add host smoke executable accepting model and PCM path. Test invalid model then real speech twice, validating output and encoder tensor types.
- [ ] Cross-compile arm64-v8a, inspect ELF and dependencies. Runtime sources fetched to ignored build tree; only project adapter and build recipe tracked.

## Task 2: Kotlin integration (app worker after Task 1)
- [ ] Write missing-model catalog test and observe failure.
- [ ] Add LocalBatchRecognizer, QwenGgufRecognizer; route QWEN_GGUF before sherpa configuration.
- [ ] Update batch cache/types, serialize calls, check cancellation/deadline, bound no-VAD-result fallback.
- [ ] Add pinned catalog entry, adapt file-shape tests and arm64 UI filtering without affecting existing model defaults.
- [ ] Run focused regression tests.

## Task 3: Build and delivery (parent)
- [ ] Update README and NOTICE for model/runtime licenses, usage and build reproduction.
- [ ] Run unit tests, native smoke and assembleDebug; verify APK signature and native packaging.
- [ ] Obtain independent spec/code review, fix material findings, repeat impacted checks.
- [ ] Commit source and provide APK path and hash, distinguishing phone validation from build results.
